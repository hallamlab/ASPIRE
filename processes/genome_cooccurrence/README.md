# Genome co-occurrence

This optional analysis builds separate proportionality co-occurrence networks
from species-level metagenomic and metatranscriptomic raw recruitment counts.
It is intentionally descriptive: the small selected genome catalog bounds the
taxa that can appear, and ASV-derived ecological-module, indicator, and TITAN
overlays are propagated annotations rather than genome-level tests.

`prepare_genome_cooccurrence.py` selects one assembly per GTDB species from the
configured genome-quality table using the deterministic hierarchy MIMAG high
before medium, then greater assembly length, greater completeness, lower
contamination, greater N50, and genome identifier. It writes assay-specific
raw-count matrices plus complete selection, sample-total, node-metadata, and
ASV-link audits. Species-level counts are used for inference; the selected
assembly supplies the stable node identifier, taxonomy, quality metadata, and
ASV linkage for that species. This avoids discarding recruitment assigned to
nonrepresentative assemblies of the same species.

For each assay, samples are closed and zeros are replaced multiplicatively by
the configured fraction of the smallest positive part before CLR
transformation. Before those operations, genome-sample raw recruitment below
the configured minimum is set to zero; a minimum of zero disables this floor.
The current SI configuration uses no positive-read floor
(`minimum_read_count: 0`), so every positive genome-recruitment signal is
retained. Counts are then averaged across every
eligible genome belonging to each species, including zero-recruitment genomes
in the denominator. This prevents species with more genome representatives
from receiving a larger value solely because more assemblies were available.
Pairwise Lovell/Erb proportionality is calculated as
`rho_p = 1 - Var(log(x_i/x_j)) / (Var(clr_i) + Var(clr_j))`. Whole cruises are
resampled with replacement within season to estimate edge recovery, direction
consistency, and percentile confidence intervals. Empirical null distributions
are generated by independently shuffling each species within season-by-depth
strata, and pairwise values are adjusted by Benjamini-Hochberg. An edge must
pass the configured absolute proportionality, bootstrap recovery, sign
consistency, and adjusted-significance requirements. Every tested pair and
criterion is retained, including rejected pairs. Degree-zero species remain in
the graph so absence of a supported co-occurrence is visible.

Positive edges represent concordant relative recruitment profiles and negative
edges represent contrasting profiles. Neither is interpreted as evidence of a
direct biological interaction. Native proportionality clusters are descriptive
Louvain groups calculated using absolute selected-edge weights. They are
labeled `MG-PC#` for metagenomes and `MT-PC#` for metatranscriptomes so they
cannot be confused with the independently inferred ASV ecological modules.

`plot_genome_cooccurrence.py` calculates one fixed
layout per assay and reuses it for taxonomy, abundance, centrality, native
proportionality cluster, linked-ASV ecological-module, hybrid ISA, microbial-compartment ISA,
per-measurement TITAN, and module-supported renewal-phase overlays. Displayed
renewal contrasts use “stagnation” for the internally stored `baseline` phase;
the pooled renewal overlay admits ecological modules only when their
`active_vs_baseline` test passes the adjusted-p threshold and colors them by
the sign of the pooled sample-weighted mean abundance difference. It remains a
propagation of module-level evidence and is not an ASV- or genome-level renewal
indicator test. Full and supported-edge-only
signed proportionality heatmaps provide a matrix view of the same inferred
structure when the network layout is visually dominated by large opposing
species sets. `genome_network_summary.tsv` reports the
species, sample, edge, isolate, and connected-component counts needed to audit
network support.
